# Roadmap

## Product

- Add real authentication with buyer, agent, and company workspaces.
- Connect listings to a backend API with image upload and moderation.
- Add saved searches with alerts for price and location changes.
- Add map-based discovery for neighborhoods and nearby services.
- Add appointment scheduling between buyers and agents.

## Data

- Replace mock services with API clients.
- Add server-side filtering, pagination, and sorting.
- Store favorites, messages, and CRM leads per authenticated user.
- Add audit logs for company account activity.

## Design

- Expand the visual system with reusable tokens for spacing, color, and elevation.
- Add loading, empty, and error states to every routed page.
- Improve advanced search with richer property-specific filters.
- Add more compact dashboard tables for company workflows.

## Engineering

- Add unit tests for services and permission logic.
- Add component tests for search, cards, and role switching.
- Add end-to-end tests for the buyer and agent flows.
- Add CI checks for linting, type-checking, and production builds.
